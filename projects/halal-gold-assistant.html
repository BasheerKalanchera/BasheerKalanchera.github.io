AI Halal Gold Investment Assistant

A grounded AI assistant that answers questions on Shariah-compliant ways to invest in gold — strictly from a curated knowledge base, and honest when it doesn't know.

How It Works Overview

Overview

The Challenge

Muslim investors who want exposure to gold face a confusing landscape: Gold ETFs, Sovereign Gold Bonds, digital gold and gold funds all look similar, but differ sharply on Shariah compliance — physical backing, interest income and certification all matter. General-purpose chatbots answer such questions confidently but without sources, which is risky when the topic is a religious ruling.

The Solution

A Retrieval-Augmented Generation (RAG) assistant that answers only from a curated knowledge base of expert questions and answers, compiled from publicly available sources. It covers Shariah compliance of Gold ETFs and Sovereign Gold Bonds, AAOIFI standards, compliance screening lists, Zakat on gold investments and regulation in India. When the knowledge base doesn't cover a question, the assistant says so plainly instead of guessing — and records the question so the knowledge base can be improved.

Key Features

  • Grounded Answers Only: The model is instructed to answer strictly from retrieved context and to use no outside knowledge
  • Honest "I Don't Know": A fixed fallback response when the answer isn't in the knowledge base — no invented rulings
  • Self-Improving Knowledge Base: Unanswered questions are logged to Google Sheets, showing exactly which gaps to fill next
  • Disclaimer-First Design: Clearly states that it is not investment or Shariah advice

Engineering Highlights

  • Question-Answer Integrity: The knowledge base is split on explicit section markers, so each question is always retrieved together with its complete answer — never a half-answer cut mid-way
  • Fallback as a Signal: The fixed "not enough information" response doubles as a trigger — the app detects it and logs the question automatically
  • Local Embeddings: Instruction-tuned Instructor embeddings run on the server itself, so searching the knowledge base costs nothing — only answer generation calls Gemini
  • Built Once, Reused: The embedding model and search index are cached, so only the first question pays the start-up cost
  • Stable Content IDs: Each knowledge-base section is identified by a SHA-256 hash of its content, giving consistent, duplicate-safe references
  • Consistent Answers: Generation runs at zero temperature, so the same question gets the same answer

How It Works

Every question follows the same path: find the most relevant knowledge, answer only from it, and feed anything unanswered back into improving the knowledge base.

Ask

The user types a question about halal gold investing

Retrieve

Semantic search finds the 10 most relevant Q&A sections

Ground

Gemini writes an answer using only those sections

Answer

A clear answer — or an honest "not enough information"

↺ Unanswered questions are logged to Google Sheets to grow the knowledge base

Search runs entirely on the app's own server using local embeddings and a FAISS index; only the final answer is generated by Google's latest Gemini models.
