AI Stock Research Workbench

Enterprise-grade, multi-agent stock analysis platform that automates comprehensive equity research through intelligent orchestration of 7 specialized AI agents

Launch Application Explore Features

Overview

🎯 The Problem

Traditional equity research is time-intensive, requiring analysts to manually download and parse 10 years of financial statements, read hundreds of pages of earnings transcripts and presentations, cross-reference credit ratings and regulatory filings, and synthesize qualitative and quantitative insights into actionable investment theses.

Result: A single comprehensive stock report can take 8-12 hours of analyst time.

💡 The Solution

A crew-based multi-agent workbench that orchestrates 7 specialized AI agents through a LangGraph state machine, each focusing on a distinct research dimension. The system automates data acquisition from Screener.in, parallelizes analysis across quantitative, qualitative, strategy, risk, and valuation domains, and synthesizes insights into professional PDF reports with charts, tables, and investment recommendations.

Impact: Reduces research time from 8+ hours to under 10 minutes per stock.

Key Capabilities

  • Automated data acquisition from Screener.in (India's leading financial data platform)
  • Parallel analysis across 7 specialized AI agents
  • Professional PDF reports with embedded charts and tables
  • Stateless architecture enabling true serverless deployment
  • Intelligent model fallback for 99%+ completion rate
  • 10 pre-configured research workflows from full analysis to targeted deep-dives

🏗️ System Architecture

The workbench uses LangGraph for stateless state management with io.BytesIO virtualization to handle Excel/PDF files in-memory. The Resilience Governor provides automatic model fallback (primary Gemini model ⇄ lightweight Gemini model) and retry logic. Below is the complete architecture showing all 7 agents and their data flow.

👥 The Agent Crew

Seven specialized AI agents work in orchestrated harmony, each focusing on a distinct dimension of equity research

📥

Screener Download Agent

The Data Orchestrator

Authenticates with Screener.in using Playwright automation and downloads 10-year financial statements, credit reports, analyst presentations, and earnings transcripts. Populates shared state with structured ByteStream objects for downstream agents.

Tech: Playwright, BeautifulSoup, Pandas
📊

Quantitative Agent

The Number Cruncher

Parses Excel ByteStreams to analyze 40+ financial metrics and generates time-series visualizations including revenue/profit trends, margin analysis, and cash flow patterns. Identifies inflection points and anomalies in financial performance.

Output: Interactive charts + narrative insights on financial health
🎯

Strategy Agent

The Business Decoder

Extracts strategic pillars from quarterly investor presentations through PDF parsing. Identifies growth drivers, capital allocation priorities, and management guidance. Detects shifts in business model or market positioning.

Output: Strategic roadmap summary with key initiatives
⚠️

Risk Agent

The Forensic Analyst

Analyzes credit rating reports for debt covenants and financial stress indicators. Scans MD&A sections for operational/regulatory risks and flags red flags like declining coverage ratios and rising contingent liabilities.

Output: Credit risk scorecard with early warning indicators
🔍

Qualitative Agent

The Deep-Dive Specialist (Sub-Crew)

A crew within a crew, comprising 4 mini-agents: SEBI Violation Checker (live search of regulatory orders), Latest Earnings Analyzer (management tone extraction), QoQ Concall Comparator (sentiment tracking), and Scuttlebutt Investigator (employee reviews and news sentiment).

Output: Comprehensive qualitative risk/opportunity matrix
💰

Valuation Agent

The Peer Benchmarker

Fetches peer group financial data for same-sector companies and compares P/E, P/B, EV/EBITDA, ROE versus industry averages. Identifies whether stock is trading at discount/premium to intrinsic value.

Output: Relative valuation matrix + fair value range
📝

Synthesis Agent

The Report Writer

Aggregates outputs from all 6 specialist agents and generates structured investment thesis with executive summary, bull/bear cases, conviction rating (1-5 scale), and key catalysts and risks.

Output: 15-20 page PDF report with embedded charts

🔧 Technical Highlights

Multi-Modal Document Processing

  • Excel Parsing: pandas + openpyxl for financial statement analysis
  • PDF Extraction: PyPDF2 + GPT-4 Vision for presentation/transcript parsing
  • Web Scraping: Playwright with session management for authenticated data access

Intelligent Agent Communication

  • Shared State Object: All agents read/write to a unified StockAnalysisState (TypedDict)
  • Conditional Edges: LangGraph routes data based on availability (e.g., skip Strategy Agent if no PPT found)
  • Parallel Execution: Quant, Strategy, and Risk agents run concurrently for 3x speedup

Production-Grade Features

  • TPM Rate Limiting: 10-second cooldown between batch analyses to respect API quotas
  • Incremental Commits: Results saved immediately after each stock for crash recovery
  • Workflow Modes: Users can run full analysis or isolated deep-dives (e.g., "Valuation Only")
  • Batch Processing: Analyze 20+ stocks sequentially with automatic ZIP export

Model Architecture

Primary Models: Google's latest Gemini models — a higher-capability model for heavy reasoning tasks and a lightweight model for data extraction

Fallback Strategy: Token limit exceeded → Switch to lightweight model | Request quota hit → Retry with exponential backoff

Total failures: <1% in production

🚀 What Makes This Special

Innovation #1

Crew-of-Crews Architecture

The Qualitative Analyst itself manages 4 sub-agents, demonstrating hierarchical agent coordination—a pattern rarely seen in production systems.

Innovation #2

Zero-Disk Orchestration

Files never touch the filesystem. All data flows through memory buffers (io.BytesIO), enabling true serverless deployment.

Innovation #3

Adaptive Workflow Engine

Users can invoke any sub-graph in isolation (e.g., just run Risk Agent), making this a research toolkit rather than a monolithic pipeline.

Innovation #4

Multi-Modal Input Fusion

Combines structured data (Excel), unstructured text (PDFs), and real-time web searches into a unified analytical framework.
